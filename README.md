# Analogy Teacher

> **"如果你不能用生活例子解释一个概念，你就没有真正理解它。"**

一个 Claude Code skill。把任意学术论文的任意页面，变成**零基础可独立阅读的完整教材**——从日常现象开场，到课后思考题收尾。

## 效果对标

解读质量对标以下两份"零基础教学"文档（可在技能作者的桌面上找到）：

| 对标文档 | 一页论文 → 教学文档的篇幅 |
|---------|--------------------------|
| `论文第五页详解_零基础教学.md` | 调和函数数学基础（十步递进教学） |
| `论文第七八页详解_零基础教学.md` | 势场三步构建 + 两种路由算法 + 复杂度分析 + Fig.6 |

**标准**：读者不需要看原论文，仅读此教学文档就能建立对该页内容的完整理解。

## 触发方式（说人话）

```
讲懂我 [概念]
把这篇论文第X页讲懂
帮我打个比方
用人话翻译这个公式
用类比解释 A 和 B 的区别
精读这篇论文
teach me this like I'm 5
```

## 你会得到什么

每页论文展开为一份包含以下全部要素的独立教材：

- 页面定位（这一页在论文中的位置和前因后果）
- 日常现象破冰（绝不从论文术语开始）
- 手算数字例子（真正走通一遍计算）
- 每个公式的"逐符号含义表 + 人话翻译"
- ASCII 示意图（至少3处）
- "工程直觉"标注（所以这意味着在实践中...）
- 同场景行为对比（当对比两个方案时）
- 知识地图（本页所有概念的关联图）
- 3-5 个课后思考题
- 下一站预告
